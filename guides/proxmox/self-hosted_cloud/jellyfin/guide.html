Primary Community Scripts — Jellyfin

community-scripts.org/scripts/jellyfin

The one-line LXC installer run from the Proxmox host shell. Creates an unprivileged Debian LXC with Jellyfin from the official repo. Read the script page before running: it lists default resources (which you may want to bump) and post-install notes. Repo / how the scripts work: github.com/community-scripts/ProxmoxVE

Bind-mounting media storage (2TB HDD)

Media lives on the host 2TB ext4 HDD; the container gets it via an mp0: bind-mount line in /etc/pve/lxc/<vmid>.conf. Decided model: bind-mounts, no SMB/NFS. Video walkthrough showing the exact config-file edit (~14:30) plus library setup and Roku client: youtube.com/watch?v=uu9PvIBYrWk

NVENC transcode setup (inside Jellyfin)

GPU access itself is covered on the GPU page (nvidia-container-toolkit route, host owns the driver). Inside Jellyfin: Dashboard → Playback → Transcoding → select NVENC hardware acceleration. The jellywatch guide covers the container-side verification steps (check /dev/nvidia* nodes are visible, then force a transcode and watch nvidia-smi load): jellywatch.app — Jellyfin Proxmox LXC/VM GPU passthrough 2026

Proxmox forum tutorial (device-node route — useful background on which /dev/nvidia* nodes matter even if you use the toolkit route): forum.proxmox.com — Jellyfin LXC with Nvidia GPU transcoding

Gotchas and notes

NVENC session cap The 3060 Ti driver allows ~3–5 concurrent NVENC sessions. Only bites when several people transcode at once. The keylase/nvidia-patch removes the cap if you ever need it.
Funnel bandwidth Community reports put Funnel relay throughput around 5–10 Mbps. Remote (LTE) streaming at high bitrate may struggle. Test a real Roku-over-LTE session before inviting relatives. Decided fallback: Cloudflare Tunnel on an existing CF domain.
Software-transcode decision superseded Earlier project notes said "software transcode, no GPU unless needed." Josh decided 2026-10-05: GPU (NVENC) is the path for both Jellyfin and Immich. 3060 Ti was chosen for exactly this.
Per-user accounts Each family member gets their own Jellyfin account (decided). Set up libraries and permissions before sharing the Funnel URL.
