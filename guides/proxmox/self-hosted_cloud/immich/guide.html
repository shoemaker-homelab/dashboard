Primary Official install — Docker Compose

docs.immich.app/docs/install/docker-compose

The authoritative procedure. Create immich-app/, download docker-compose.yml + .env, set UPLOAD_LOCATION (bind-mounted 2TB HDD path), set a random DB_PASSWORD (A-Za-z0-9 only), pin IMMICH_VERSION, then docker compose up -d. Use docker compose, not docker-compose.

Docker-in-LXC base container

Immich's own community install pattern: create a Docker-enabled unprivileged LXC (community helper scripts have a one-line "Docker LXC" installer — search "Docker" on community-scripts.org), then follow the official compose guide inside it. The original community walkthrough with bind-mount and UID/GID permission details: github.com/tteck/Proxmox discussion #1668

Container requirements: nesting=1 (and typically keyctl=1) on the LXC. Must be unprivileged — privileged LXC + Docker = host-root risk.

Resource sizing + LXC gotchas

ricardogil.com — Immich on Proxmox LXC 2026

  • Minimum 6 GB RAM / 2 vCPU; recommended 8–16 GB / 4 vCPU for the initial library scan.
  • x86-64-v2 CPU requirement (v3.0+) — Zen3 is fine.
  • Reverse proxy note: large uploads need a big body-size limit on any proxy in front (relevant to the CF Tunnel fallback).

GPU for ML

Immich's machine learning (face recognition, CLIP search) can run on the shared 3060 Ti via the nvidia-container-toolkit route — same host driver, no per-container driver install. If RAM pressure is a problem, the ML container can be pointed at the GPU or temporarily disabled in the compose file. Decision (2026-10-04): ML capped or disabled initially; revisit after the first library scan.

Ingress

Tailscale Funnel, same as Jellyfin: https://immich.tailda8422.ts.net. Official docs: tailscale.com/kb/1223/funnel. Fallback: Cloudflare Tunnel (free, unlimited subdomains) if Funnel limits bite.

Gotchas and notes

Version pinning Pin IMMICH_VERSION in .env and read the release notes before every upgrade — Immich does breaking DB migrations. Back up before upgrading (restic plan covers this).
Sharing model — decide before inviting relatives Open question: shared albums vs one shared-pool account for family photos. Per-user libraries + dedup was the requirement that chose Immich (both spouses upload the same photo → one copy, both access). Resolve the model before step 4 (user accounts).
Upload location UPLOAD_LOCATION must point at the bind-mounted 2TB HDD, not container-local disk — the 500G NVMe is OS/VM disk and will fill.
Phone auto-upload Test with your phone before family rollout (step 6 of the project plan).
